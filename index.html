Котик-ИИ офлайн-режим

🔑 Подключить умный ИИ (Claude)

Без ключа котик отвечает в простом офлайн-режиме. С ключом Anthropic он становится по-настоящему умным: отвечает на любые вопросы, пишет код и тексты.

Ключ хранится только в вашем браузере и уходит только на api.anthropic.com. Получить ключ: console.anthropic.com. Запросы по API платные.
